# Attribution and distribution boundary

The early local prototype was inspired by the community WB Enhance Prompt
sharing workflow at <https://linux.do/t/topic/2860395>.

The public distribution contains this project's own implementation and newly
written standard/creative prompt templates. It does not distribute that
third-party share archive or its verbatim prompt templates, and it does not
claim to be an official WorkBuddy, Augment, or ZCode product.

ZCode and its bundled React/Lexical/application assets are not distributed in
this repository or in release archives. The patch operates on the user's
existing installation. The short build markers and hashes in the adapter
identify the supported builds; they do not grant rights in the application.

The optional Python runtime is downloaded directly from python.org only when
needed, with a pinned SHA-256 check. Its own license files remain with the
downloaded runtime. It is not included in this project's source ZIP.
